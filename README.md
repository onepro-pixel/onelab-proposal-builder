# Sales Proposal Builder

Bygg ett internt verktyg för OneLab (www.onelab.se) där säljare gör om mötesanteckningar från Sales Kong till skräddarsydda kundförslag.

Inloggning för OneLab-anställda (e-post och Google). Varje säljare ser och kan redigera sina sparade förslag.

Ny offert: fält för kundnamn, kontaktperson och ett stort fält där anteckningarna klistras in.

AI skriver förslaget på svenska utifrån anteckningarna och OneLabs tjänster: hälsoundersökningar, lagstadgade medicinska kontroller (spirometri, hörseltest, vibrationstester med läkarintyg, nattarbete), tillägg som syn och PSA, hälsoprogram, HR-portalen (medarbetarundersökningar, pulsverktyg, sjuk- och friskanmälan) och den transparenta prismodellen med fast pris per person.

Förslaget visas som en snygg sida som går att redigera och sedan laddas ner som PDF eller delas med kunden via en publik länk.

Design: OneLabs färger, typsnitt och bildstil från onelab.se. Använd den bifogade Exeger-PDF:en som förebild för struktur och ton.

En inställningssida där vi kan uppdatera tjänstebeskrivningar och standardtexter som AI:n använder.
